Executive Summary: How Much is Norb Equal vs. Different?

Norb achieves 100% developer workflow parity with OrbStack while departing fundamentally from OrbStack's proprietary, closed-source design in favor of modern, native Apple Silicon system primitives.

Common Interface Exact OrbStack Parity (Equal)

  • Dual-Mode CLI: norb short runner (norb uname -a) and norbctl administration (clone, rename, top, debug, mount, k8s).
  • Standard Docker Drop-In: docker --context norb pointing to ~/.norb/run/docker.sock with dynamic port forwarding to 127.0.0.1:PORT.
  • Local Domain Routing: Automatic HTTP/HTTPS routing for *.norb.local, multi-level compose <svc>.<proj>.norb.local, and @port overrides.
  • Apple Silicon Rosetta 2: Hardware-accelerated x86_64 container and Linux binary execution inside ARM64 guests via binfmt_misc.
  • Local Kubernetes (K3s): One-command cluster provisioning (norb k8s enable), port 26443 API tunnel, and instant kubectl compatibility.
  • SSH Agent & Config Forwarding: Automatic ~/.ssh/config managed block and seamless $SSH_AUTH_SOCK forwarding into Linux guests.

Modern Architecture How Norb is Better (Different)

  • 100% Open Source & Rust: Zero proprietary lock-in, zero DRM, zero license servers, zero telemetric reporting.
  • Native APFS Copy-on-Write: Sub-millisecond instant disk clones via macOS libc::clonefile—zero duplicate storage until written.
  • Native AppKit Menu Bar (< 3 MB): Pure Cocoa NSStatusBar status item ( Norb) without bloated Electron or WebKit UI processes.
  • Declarative YAML Engine: Human-readable ~/.norb/config.yaml with intelligent defaults, schema validation, and atomic writes.
  • Non-Invasive Resolver: Native macOS /etc/resolver/norb.local routing without tampering with system DNS or /etc/hosts.
  • True Multi-Distro Micro-VMs: Cleanly isolated micro-VMs per machine rather than a monolithic black-box container sandbox.
